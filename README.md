## 📋 Project Overview
This website presents research on whether LLMs can:
1. Understand MBTI concepts
2. Think about personalities from a human perspective
3. Provide accurate MBTI-related responses

## 🎯 Research Questions
- Do LLMs understand MBTI?
- Could LLMs think about personalities from a human perspective?
- How accurate are LLMs' responses in MBTI?
